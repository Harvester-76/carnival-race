# Короткий промпт для Claude-агента на Windows (полная задача лежит в Мионике)

Ты Claude-агент на чистом Windows-компьютере (ни Godot, ни проекта, только этот удалённый терминал Orca). У тебя подключена Мионика. Твоя задача лежит там: проект `carnival-race`, задача **TSK-8 «Windows: сборка игры и установщик»**. Прочитай её целиком (`get_atom` TSK-8 с содержимым) и выполняй по шагам: сначала шаг 0 «проверка кодировок» (раньше на Windows вместо кириллицы вылезали крякозябры), потом клонирование репозитория, Godot 4.7.2, экспорт и установщик Inno Setup с картинками из меню игры.

Коротко о правилах (подробности в задаче): говори со мной по-русски и коротко; перед каждой установкой пиши, что ставишь, и скачивай только с официальных сайтов; вход в GitHub (`gh auth login`) делаю я, пароли и токены сам не вводи; игровой код не трогай, найденные баги описывай в отчёте; свои файлы коммить в ветку `windows-build`, не в `main`; отчёт запиши в конец TSK-7 и поставь TSK-8 статус `review`.
