# Промпт для Claude-агента на Windows: сборка «Карнавальской Гонки» и установщик

Ты работаешь на чистом Windows-компьютере через удалённый терминал. Здесь ничего нет: ни Godot, ни проекта. Твоя задача — собрать игру для Windows и сделать красивый установщик с деинсталлятором. Говори со мной по-русски, коротко. Всё, что делаешь и решаешь, дублируй в Мионику (см. конец).

## Что за проект
«Карнавальская Гонка» — демо-прототип космической гонки по мотивам цикла Ольги Громыко «Космоолухи» (ирония, живая речь, тотализатор, гонщики-раздолбаи). Движок: Godot 4.7.2-stable (Forward+, физика Jolt). Репозиторий (приватный): https://github.com/Harvester-76/kosmooluhi-karnaval-race, ветка main. Нужна только папка `Godot_Test` (остальное — Blender-исходники, они тяжёлые и не нужны).

## Правила
- Скачивать можно только с официальных сайтов: Git, Git LFS, GitHub CLI, Godot 4.7.2-stable (win64 + export templates той же версии, с github.com/godotengine/godot/releases), Inno Setup 6 (jrsoftware.org), rcedit (github.com/electron/rcedit), ImageMagick. Перед каждой установкой коротко пиши, что ставишь. `winget` можно, но Godot — строго 4.7.2.
- Вход в GitHub (приватный репозиторий): если нужен интерактивный `gh auth login`, остановись и попроси меня выполнить шаг; пароли и токены сам не вводи и не ищи.
- Не трогай игровой код. Исключения: файлы экспорта и иконка. Если на Windows найдёшь баг игры — не чини молча, опиши в отчёте (что, где, как воспроизвести). Не перезаписывай `bot_genes.json`.
- Свои файлы (пресет экспорта, скрипт установщика, картинки установщика) коммить в отдельную ветку `windows-build`, не в `main`. Если нет прав на push — положи в папку и скажи путь.
- Долгие команды запускай в фоне и смотри лог, интерактивных вопросов не оставляй.

## Шаг 0. Сначала проверь кодировки (на Windows раньше вылезали крякозябры вместо кириллицы)
- Консоль: `chcp 65001`; в PowerShell `[Console]::OutputEncoding = [Text.UTF8Encoding]::new($false); $OutputEncoding = [Console]::OutputEncoding`; `git config --global core.quotepath false`; `git config --global core.autocrlf false` (иначе .gd/.cfg/.godot получат CRLF и лишние правки). Выведи в консоль строку «Карнавальская Гонка — ёЁ» и убедись, что она читается.
- Файлы пиши только в UTF-8: через `[IO.File]::WriteAllText($path, $text, [Text.UTF8Encoding]::new($false))` (без BOM), либо PowerShell 7. Никогда не используй в Windows PowerShell 5 `Set-Content`/`Out-File`/`>` без `-Encoding utf8` (они дают ANSI или UTF-16). Исключение: скрипт Inno Setup `.iss` с русским текстом сохраняй в UTF-8 С BOM, иначе ISCC прочтёт его как ANSI и в мастере будут иероглифы.
- После клона проверь, что `project.godot`, `demo_ui.gd`, `menu_skin.gd` читаются как UTF-8: в `project.godot` имя проекта «Карнавальская Гонка», в `demo_ui.gd` есть «Планы и режимы», без символов «Ð», «Ñ», «Р°» и «�».
- После экспорта запусти игру и проверь на экране кириллицу: меню, «Об игре», «Достижения», HUD («ЗДОРОВЬЕ»), названия кораблей. Папка прогресса должна называться `...\app_userdata\Карнавальская Гонка` без мусора. Если где-то крякозябры — остановись, выясни причину (кодировка файла, шрифт, консоль) и расскажи.
- Мионика: русский текст в свои вызовы передавай как есть (не через командную строку), после записи прочитай атом обратно и сверь.

## Шаги
1. **Репозиторий без лишнего трафика.** Лимит Git LFS на скачивание ограничен, поэтому только нужное:
   `set GIT_LFS_SKIP_SMUDGE=1`, `git clone --filter=blob:none --no-checkout <url> kk`, `cd kk`, `git sparse-checkout set Godot_Test`, `git checkout main`, затем `git lfs pull -I "Godot_Test/**"` (около 370 МБ). Проверь, что в `Godot_Test/ship/ship.glb` настоящий файл (~120 МБ), а не текстовая заглушка на 130 байт. Если LFS упрётся в квоту (ошибка про budget/quota) — остановись и сообщи.
2. **Godot.** Распакуй Godot 4.7.2-stable, поставь export templates (Editor → Manage Export Templates или распаковать `.tpz` в `%APPDATA%\Godot\export_templates\4.7.2.stable\`). Пропиши путь к `rcedit.exe` в Editor Settings (Export → Windows → rcedit).
3. **Импорт и запечённые корабли.** В папке `Godot_Test`: `godot --headless --path . --import` (первый раз долго), затем `godot --headless --path . --script res://tools/bake_variants.gd` — создаёт `ship/variants/*.scn` (в репозитории их нет, без них игра соберётся, но корабли будут строиться при старте минутами). Это обязательный шаг перед экспортом.
4. **Проверка запуска из редактора/консоли.** `godot --path .` — окно открывается, меню, музыка, старт гонки, геймпад (если есть). Закрой. Ошибок «Parse Error»/«Failed to load» в логе быть не должно.
5. **Экспорт.** Создай пресет «Windows Desktop», x86_64, `Godot_Test/export_presets.cfg`. Название приложения «Карнавальская Гонка», версия 0.1.0, компания «Harvester», описание «Демо-прототип космической гонки». Иконка — из `Godot_Test/installer/app_icon.png` (1024×1024, потом сделай из него `app_icon.ico` со слоями 16/24/32/48/64/128/256 через ImageMagick; если файла в ветке ещё нет, временно возьми `menu_v2/ach/will.png` и напиши мне, что иконка временная). Включи модификацию ресурсов через rcedit (иконка, ProductName, FileDescription, версия). Pck встраивать в exe или оставить рядом — выбери по размеру/скорости старта и скажи, что выбрал. Из экспорта исключи: `tools/*`, `evo/*`, `*.md`, `installer/*`, `menu_v2/*.html`, `menu_v2/*.py`, `menu_v2/ach/_source_*.png`, `flight_log*`, `windows_build_prompt.md`. Результат: `build\KarnavalskayaGonka.exe` (+ pck, если отдельно). Ожидаемый размер порядка 0,8–1 ГБ без сжатия: напиши, сколько вышло.
6. **Проверка собранного exe.** Запусти `build\KarnavalskayaGonka.exe`, проверь: меню грузится, фоны и шрифты на месте, музыка и звуки, старт гонки, ссылка в «Об игре» открывает диалог с QR, на странице «Достижения» видно иконки, достижение «Установщик Винды» выдаётся само (игра сама определяет Windows). Файл прогресса пишется в `%APPDATA%\Godot\app_userdata\Карнавальская Гонка\controls.cfg`. Скриншот не нужен, нужен лог (`--verbose` по желанию).
7. **Установщик (Inno Setup 6).** Файл `Godot_Test/installer/KarnavalRace.iss`:
   - Язык русский (`compiler:Languages\Russian.isl`), `WizardStyle=modern`, `AppName=Карнавальская Гонка`, `AppVersion=0.1.0`, `DefaultDirName={autopf}\KarnavalRace` (ASCII-путь), `DefaultGroupName=Карнавальская Гонка`, LZMA2/ultra64 solid-сжатие, `OutputBaseFilename=KarnavalskayaGonka_Setup_0.1`, `SetupIconFile=app_icon.ico`, `UninstallDisplayIcon`, ярлык в «Пуск» и необязательный на рабочем столе, пункт «Запустить игру» в конце. Деинсталлятор — штатный (запись в «Установке и удалении программ»).
   - **Картинки из меню игры** на шагах мастера (макеты 1672×941 лежат в `Godot_Test/menu_v2/bg/`: porthole, bar, hangar, cabin, engine, corridor, space, exit, about). Нарежь их через ImageMagick в BMP: вертикальная полоса 328×628 для `WizardImageFile`/страниц приветствия и завершения (кадрируй по центру самого красивого фрагмента, снизу чуть затемни) и маленькая 110×110 для `WizardSmallImageFile`. Для разных шагов меняй картинку из `[Code]` (`CurPageChanged`, `WizardForm.WizardBitmapImage.Bitmap.LoadFromFile` / `WizardSmallBitmapImage`): приветствие — porthole, информация — about, выбор папки — hangar, задачи — bar, готовность — cabin, установка — engine (и по ходу меняй фразы статуса через `CurInstallProgressChanged`), завершение — space; деинсталлятор — exit. Картинки упакуй в установщик (`ExtractTemporaryFile` или `dontcopy`).
   - Если на каком-то шаге не получается красиво — упрости, но на приветствии, установке и завершении картинки обязательны.
   - Деинсталлятор в конце спрашивает «Удалить и ваши грамоты, рекорды и настройки?» (по умолчанию «Нет»). Если «Да», удали папку `%APPDATA%\Godot\app_userdata\Карнавальская Гонка`.
   - Тексты мастера — ниже, подставь их в `[Messages]`, `[CustomMessages]`, `InfoBeforeFile` и в код.
8. **Проверка установщика.** Собери (`ISCC`), поставь тихо в временную папку (`/SILENT /DIR=...`), запусти игру из неё, закрой, запусти деинсталлятор. Потом прогони мастер вручную в интерактиве, если у меня есть доступ к экрану; если нет — сделай скриншоты шагов (например, через `ImageMagick`/`nircmd`/Win32 PrintWindow) и положи в `build\screens\`. Окно SmartScreen для неподписанного exe — нормально, лишь отметь это в отчёте.
9. **Отчёт.** Запиши в Мионику (проект `kosmooluhi-karnaval-race`, добавь в конец задачи TSK-7 через `batch_crud` `edit_atom_content` с `append`, сначала прочитай TSK-7): версии инструментов, где что лежит, размеры exe и установщика, время сборки, что не получилось, найденные баги игры, что нужно доделать. Мне — коротко в чате: путь к установщику и три пункта «что проверить глазами».

## Тексты мастера установки (стиль книг: ирония, разговорная речь, букмекеры и тотализатор). Используй как есть, при необходимости чуть подгони под ограничения длины
- Название окна: «Мастер установки: Карнавальская Гонка»
- Приветствие, заголовок: «Добро пожаловать на Карнавал!»
- Приветствие, текст: «Вас приветствует Мастер установки — существо терпеливое, как навигатор при пилоте-лихаче. Сейчас мы поселим на вашем компьютере гоночный каньон длиной в несколько сотен километров, двенадцать отчаянных пилотов (трезвых не обнаружено) и четыре корабля, каждый из которых хоть раз да терял двигатель. Закройте, пожалуйста, прочие программы: им лучше не знать, что будет дальше.»
- Перед установкой (отдельная страница «Прочтите, пока не поздно»): «Это демо-прототип по мотивам цикла «Космоолухи». Здесь только малая часть задуманного: трасса сгенерирована, соперники — боты, сетевой игры и судей пока нет. Часть картинок (уровни сложности) взята из книги без разрешения художника, остальные нарисованы нейросетью; мы это исправим, как только обзаведёмся собственными. Если что-то сломается — это не баг, это интрига.»
- Выбор папки, заголовок: «Куда парковать?»; подзаголовок: «Выберите ангар для игры»; текст: «Игра встанет в указанную папку. Нужно примерно %1 свободного места: каньон велик, а скалы без потери живописности не сожмёшь. Хотите другой ангар — нажмите «Обзор». Не хотите думать — нажмите «Далее».»
- Дополнительные задачи, заголовок: «Мелочи для комфорта»; чекбоксы: «Значок на рабочем столе (чтобы стартовать, не сверяясь с картой)», «Ярлык в меню «Пуск»»
- Готовность, заголовок: «Ставки приняты»; текст: «Взносы внесены, ставки сделаны, корабли заправлены. Нажмите «Установить», и пути назад не будет (то есть будет, через деинсталлятор, но это уже позор).»
- Установка, заголовок: «Идёт заправка»; подзаголовок: «Раскладываем каньон по полочкам»; статусы по ходу (меняй по процентам): «Разворачиваем каньон…» → «Раскрашиваем скалы в полоску…» → «Прикручиваем моторы (иногда даже к кораблям)…» → «Принимаем ставки на дальних кораблей…» → «Подкупаем судей (шутка!)…» → «Разливаем топливо и прочие жидкости…» → «Ещё чуть-чуть, борт уже на старте…»
- Завершение, заголовок: «Стартуем!»; текст: «Установка закончена. Нажмите «Готово», чтобы выйти из мастера (из каньона так просто не выйти). Желаем лёгкого полёта и ни одной оторванной детали.»; чекбокс: «Лететь немедленно!»
- Деинсталлятор, подтверждение: «Вы действительно хотите покинуть Карнавал? Каньон будет убран, пилоты распущены, ставки возвращены.»; вопрос про данные: «Стереть и ваши грамоты, рекорды и настройки? Они вам ещё пригодятся, но решать вам.»; завершение: «Карнавал свёрнут. Приходите ещё: каньон помнит всех, а букмекеры — тем более.»
- Ошибки/занято: «Игра сейчас запущена. Остановите гонку и закройте её, иначе мастер её не догонит.»

## Критерии готовности
Есть `KarnavalskayaGonka_Setup_0.1.exe`, он ставит игру, игра запускается из «Пуска» и с рабочего стола, деинсталлятор убирает всё и спрашивает про данные. На шагах мастера видны картинки из меню игры, тексты как выше. В Мионике записан отчёт, в ветке `windows-build` лежат `export_presets.cfg` и `installer/`.
