# Пакет для Unreal: корабль «Третий шанс»

Собран из `spaceship_4.blend` скриптом `tools/export_unreal.py` (можно запускать повторно: `blender -b spaceship_4.blend -P tools/export_unreal.py`).
Содержимое: Meshes (FBX), Textures, Data (таблицы), MATERIALS.md (описание материалов). Версия Unreal не уточнялась; ориентир UE 5.3+.

## Что где
- `Meshes/Ship/`: SM_Hull_Body (корпус, уплотнённый под вмятины, 42 тыс. вершин, есть цвет вершин DMG), SM_Hull_Body_LOD1 (облегчённый без вмятин для NPC вдали), SM_Hull_Solid (замкнутый «твёрдый» корпус для взрыва по Voronoi). Пивот в начале координат корабля. [3 файла, 5.9 МБ]
- `Meshes/Parts/`: отлетающие и подвижные детали: 16 моторов, 2 крыла, 6 прожекторов, 11 стёкол, 2 люка. Пивот в точке крепления, вместе с мешем идёт коллизия `UCX_<имя>_01` в том же FBX. [37 файла, 4.8 МБ]
- `Meshes/Interior/`: интерьер (рубка, кают-компания, коридор, 10 кают, грузовой отсек). Пивот в начале координат корабля, все ставятся в (0,0,0) компонента корабля. [28 файла]
- `Meshes/Debris/`: 3 плиты-шестигранника SM_HexPlate_A/B/C.
- `Textures/`: только используемые текстуры (имена без изменений).
- `Data/assembly.csv`: где стоит каждая деталь (положение в сантиметрах Unreal), какая коллизия; `Data/sockets.csv`: кости скелета (Exhaust_*, Shunt_* и т.д.) как места для сокетов; `Data/hex_cells.csv` и `Data/hex_lattice.json`: ячейки и формула решётки шестигранников; `Data/materials.json`: данные материалов.

## Системы координат и масштаб (проверить сразу после импорта)
- Числа в FBX в САНТИМЕТРАХ, единица FBX = 1 (см). Import Uniform Scale оставить 1, `Convert Scene Unit` значения не меняет.
- Нос корабля смотрит на +X Unreal, правый борт на +Y. Соответствие: Blender (x, y, z) -> Unreal (y, x, z) * 100 см.
- Проверка: SM_Hull_Body должен быть около 7900 см длиной по X (от -4136 до 3782 см), шириной около 2560 см. Левое крыло SM_Wing_L уходит в -Y. Если корабль повёрнут или зеркален, поправьте поворот при импорте (Import Rotation Z = 90 или -90) и не трогайте масштаб.

## Настройки импорта Static Mesh
- Combine Meshes: выкл (в частях FBX содержит меш и его UCX). Auto Generate Collision: выкл. Generate Missing Collision: выкл.
- Build Nanite: ВЫКЛ для SM_Hull_Body (WPO-вмятины). Для интерьера можно включить.
- Vertex Color Import Option: Replace (нужен для SM_Hull_Body: цвет вершин DMG, R = жёсткость, G = сегмент/4, B = область/3).
- Normals: Import Normals; Import Tangents выкл. Smoothing групп-гранями (плоские грани корпуса остаются плоскими).
- Import Materials: можно включить (создаст пустые материалы с именами слотов) или связать вручную по именам из MATERIALS.md. Import Textures: выкл (текстуры импортировать отдельно из Textures/).
- UV-каналы корпуса и деталей: 0 UVMap, 1 UV_Glow, 2 UV_Airlock, 3 UV_Damage (только у корпуса и деталей). У интерьера один канал UVMap (у части объектов UV нет).
- SM_Hull_Body_LOD1: импортировать отдельным мешем (или как LOD1 корпуса).

## Порядок
1. Импортировать Textures, затем Meshes (Parts вместе с UCX).
2. Создать материалы (сначала стекло и обшивку), назначить слотам.
3. Собрать Blueprint корабля: компонент SM_Hull_Body + компоненты деталей по `Data/assembly.csv` (положение в см, поворот 0, масштаб 1) + интерьер в (0,0,0).
4. Проверить ориентацию, масштаб, стекло (снаружи полупрозрачное, изнутри прозрачное), свечение ядер моторов.

## Повреждаемость (кратко; полный план в Мионике NOT-14)
- Вмятины: World Position Offset в материале обшивки; до 8 одновременных ударов (параметры: центр, радиус, направление, глубина, шум). Глубина вплоть до центра, интерьер при этом виден.
- Шестигранники: рисовать в материале по формуле решётки из `Data/hex_lattice.json` (островерхие, ширина 1,2 м между гранями, ряды 1,0392 м, нечётные ряды сдвинуты на W/2, проекция по доминирующей оси нормали). `Data/hex_cells.csv`: 4727 ячеек (центр, нормаль, ось, i, j, зона). Плиты SM_HexPlate_* спавнить в этих центрах.
- Отлетающие детали (моторы, крылья, прожекторы, стёкла, люки): отдельные меши с UCX, физика через Physics Asset с ломающимися констрейнтами или как физические акторы.
- Финальный взрыв: Geometry Collection из SM_Hull_Solid (Fracture Mode, Voronoi на 6-12 крупных частей).
- Зоны урона DMG: 20 зон (5 сегментов вдоль корпуса x 4 области), номера в цвете вершин.

## Известные ограничения
- Одинаковые моторы пока не сведены в общие меши (у каждого своё число граней).
- Нормали у тайлов интерьера: проверить Flip Green Channel.
- В `UV_Damage` перекрытия не перепроверялись.
