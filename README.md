# Карнавальская Гонка

Космическая гонка по мотивам цикла Ольги Громыко «Космоолухи»: узкие каньоны, срезки, соперники-боты и корабли, которые приходится беречь. Проект в разработке.

## Что планируется в будущем

Три режима игры: 
- Режим обучения с ботами:
  один игрок,
  таблица достижений внутри игры,
  различные уровни сложности
– сетевой режим:
  реальные живые соперники,
  уровень сложности определяется настройкой на сервере
- RP-режим
  управление кораблем двумя игроками - пилот и навигатор,
  настраиваемые вирт-окна для каждого участника,
  отключены механизмы дисквалификации и возвращения на трассу,
  возможно движение различной обслуживающей техники по карте,
  эвакуация участников при помощи специально выделенных экипажей,
  живое судейство организаторами гонки,
  возможно, добавление собственных кораблей

Красивая карта каньона, сделанная по описанию из книги
Разные корабли со своими характеристиками
Красивая графика на Unreal Engine

## Скачать и поиграть

Сейчас доступна **демо-версия на Godot** (прототип, не основная игра). Данный прототип создан для обкатки управления и моделей кораблей. Трасса в ней сгенерирована нейросетью и не имеет ничего общего с книжной. Графика сделана на легковесном движке Godot, для того, чтобы сделать рабочий прототип максимально быстро. В дальнейшем планируется реализация игры на Unreal Engine с красотами в стиле Гранд Каньона и крутыми эффектами, и постепенное выпиливание нейрослопа из меню.

| Платформа | Что скачать | Как установить |
|---|---|---|
| **Windows 10/11 (64 бит)** | [Релизы](../../releases): архив `KarnavalskayaGonka_0.1_Windows.zip` | Распаковать, запустить `KarnavalskayaGonka_Setup_0.1.exe`, пройти мастер установки |
| **macOS** (Apple Silicon и Intel) | [Релизы](../../releases): архив `KarnavalskayaGonka_macOS.zip` | Распаковать, перенести приложение в «Программы», первый раз открыть правым кликом → «Открыть» (приложение не подписано) |

Подробная инструкция, требования и решения частых проблем лежат в описании каждого релиза и в `README.txt` внутри архива. Управление: геймпад Xbox (желателен) или клавиатура, всё настраивается в игре.

## Как устроен репозиторий

Репозиторий ведётся по веткам. Выбирайте ветку вверху слева.

| Ветка | Что в ней |
|---|---|
| `main` | основная игра на Unreal Engine (разработка впереди) |
| `godot-demo` | демонстрационный прототип на Godot 4.7: механика, трасса, боты, интерфейс |
| `Windows_Build` | сборка демо для Windows: пресет экспорта и установщик (Inno Setup) |
| `MacOS_Build` | сборка демо для macOS: пресет экспорта |

Релизы общие для всего репозитория. Название релиза говорит, что это: `godot-demo-windows-v0.1.0` — Godot-демо для Windows. Демо-релизы помечены как pre-release.

## Что где лежит (ветка `godot-demo`)

| Папка | Назначение |
|---|---|
| `Godot_Test/` | рабочий проект Godot, главный источник истины |
| `Godot_Test/installer/` | установщик для Windows и его картинки |
| `Godot_Dev/` | копия проекта для обучения ботов |
| `Godot_Scale/` | эксперименты с масштабом |
| `Base ship/` | исходники корабля в Blender и скрипты экспорта |

## Собрать демо из исходников

1. Установите [Godot 4.7.2](https://godotengine.org/download) (обычная версия, не .NET).
2. Установите [Git LFS](https://git-lfs.com) и выполните `git lfs install`, затем клонируйте репозиторий: большие файлы (модели, картинки, звук) хранятся через LFS.
3. Откройте папку `Godot_Test` в Godot и запустите проект (F5), либо из терминала: `godot --path Godot_Test`.
